Thank you for downloading Mech_00(A)
This asset is not a standalone asset, it is an expansion for Mech_00.

This asset includes mesh body parts (arms, torsos, pelvis, etc.) for Mech_00.

The modularity from Mech_00 and the swapper script also apply to these meshes.
---
Setup the body parts with BodySwapper inside Unity
---
1 Import Mech_00A.fbx into the Unity project /Assets

3 Select the root of the Prefab and in Inspector > Robot Part Swapper (Script)
-Tick Debug Mode

5 Click Find and Add Parts from Folder

6(optional) Add the mutually exclusive Core-Palm L/R parts for the LimbGun parts

Now you can use the body swapper to swap to the new body parts.
